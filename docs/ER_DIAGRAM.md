# Entity relationship diagram

Generated by hand from `apps/api/src/db/schema/*.ts`. Column lists show keys and the most important fields only. Constraints and ownership are in [DATABASE.md](DATABASE.md).

Almost every table below also has `store_id`. To keep the diagram readable, relationships to `stores` are drawn only for top-level entities. Child tables reference parents through composite `(store_id, id)` foreign keys.
